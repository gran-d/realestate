# Real Estate API (Мини-Циан)

REST API для платформы недвижимости. Учебный проект на Go.

## Стек

- **Go** + **Fiber** — HTTP сервер
- **PostgreSQL** — база данных
- **Docker** — контейнеризация
- **Swagger** — документация API
- **JWT** — авторизация (access + refresh токены)

## Функционал

- Регистрация и вход (роли: buyer, agent, admin)
- CRUD объявлений о недвижимости
- Поиск с фильтрами (город, тип, цена, комнаты)
- Избранные объявления
- Загрузка фотографий
- Админ панель

## Запуск

1. Скопируй `.env.example` в `.env` и заполни значения
2. Запусти:
   docker compose up --build
3. Открой Swagger: http://localhost:3000/swagger/index.html
